# License provenance

These notices accompany the unmodified alphaTab 1.8.4 browser bundle.

- `alphaTab.txt`: npm package `@coderline/alphatab@1.8.4/LICENSE`.
- `alphaTab-NOTICES.txt`: preserved leading notice from `alphaTab.min.js`.
- `Apache-2.0.txt`: https://www.apache.org/licenses/LICENSE-2.0.txt (Sonivox).
- `integrated-MIT.txt`: copyrights from the alphaTab bundle notice, with the
  MIT terms published by TinySoundFont, covering the five MIT libraries.
- `TinySoundFont.txt`: https://github.com/schellingb/TinySoundFont/blob/master/LICENSE
  (also credits SFZero).
- `SharpZipLib.txt`: https://github.com/icsharpcode/SharpZipLib/blob/master/LICENSE.txt
- `NVorbis.txt`: https://github.com/NVorbis/NVorbis/blob/master/LICENSE
- `libvorbis.txt`: https://github.com/xiph/vorbis/blob/master/COPYING

Bravura and Sonivox original notices remain beside the vendor assets. Full
texts in this folder are tracked so exports include them without additional
network requests at build time. When upgrading alphaTab, review its new bundle
notices and update both the license copies and the corresponding source link
in `static/index.html`.
